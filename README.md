# Life Logger Journal

Life Logger is a smart Android journaling app that captures memories through notes, photos, voice recordings, location, and an AI-powered personal assistant.

## Features
- Smart journaling and memory saving
- AI assistant chat and voice interaction
- Voice note recording and playback
- Photo memories with date, time, and location
- Memory gallery
- Secure PIN lock
- Dark and light themes
- Beautiful modern UI

## Built With
- Java
- Android Studio
- SQLite Database
- Material Design
